# 脱敏 PPGL 病例评测汇总

> 本汇总只保留聚合指标。原始影像、标签、预测掩膜、病例映射、本地路径和原始模型输出均保存在仓库外的受控评测目录，未提交 Git。

## 评测设置

- 病例数：6 例脱敏 CT。
- 病例选择：按肿瘤真值体积分位数覆盖小、中、大体积病灶。
- 分割模型：PPGL 分割权重。
- 真值：`labels_ablation_tumor_only`。
- 报告模型：`ppgl-qwen3-32b-q4:latest`、`ppgl-qwen3-32b-q5:latest`、`ppgl-qwen3-8b-q4:latest`。
- 报告评分：检查原始语言模型输出是否遵守固定 JSON Schema、复述分割数值与侧别、覆盖接触关系并保留安全提示。该评分是规则辅助代理评分，不替代临床专家复核。

## 工程结论

1. PPGL 分割在这组脱敏病例上表现稳定，但这不是完整数据集上的泛化结论。
2. 三个语言模型均不能稳定按完整报告 Schema 输出原始 JSON；8B Q4 的 JSON 稳定性最差。
3. 因此，肿瘤体积、最大径、侧别、毗邻关系、局限性声明等固定报告字段必须继续直接由分割结果和确定性模板生成，不能依赖语言模型生成。
4. 语言模型适合承担固定字段之外的解释性文本和受证据约束的问答；其输出须经过 Schema 校验、失败回退和医生复核。
5. 该结论与当前项目的确定性指标回填方向一致，并为后续报告模块的模型路由和质量控制提供了量化依据。
